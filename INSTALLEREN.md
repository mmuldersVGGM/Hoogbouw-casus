# Hoogbouwcasus VGGM 2026 installeren

Publieke URL:
https://mmuldersvggm.github.io/Hoogbouw-casus/

## Windows – Edge
1. Open de URL in Microsoft Edge.
2. Menu (…) → Apps / Deze site installeren als app.
3. Kies Installeren.
4. Kies Vastmaken aan taakbalk.

## Android – Chrome of Edge
1. Open de URL.
2. Menu → App installeren / Toevoegen aan startscherm.
3. Bevestig.

## iPhone / iPad – Safari
1. Open de URL in Safari.
2. Tik op Deel.
3. Kies 'Zet op beginscherm'.
4. Kies 'Voeg toe'.
